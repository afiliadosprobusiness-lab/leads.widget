# Guia de usuario CRM (migracion)

## Cambio aplicado
Desde el **2026-02-28**, `leads.widget` ya no muestra la pestana `CRM` en el dashboard cliente.

## Donde gestionar CRM ahora
La operacion CRM diaria (contactos, pipeline, tareas y seguimiento) se realiza en **WhatsWidget CRM**.

## Que sigue en leads.widget
En `leads.widget` se mantiene la operacion de:
- `Widget`
- `IA`
- `Analiticas`
- `Seguridad`
- `Pagos`
- `Cuenta`

## Guia rapida para usuarios
1. Usa `leads.widget` para configurar captacion, asistente IA, seguridad y facturacion.
2. Usa **WhatsWidget CRM** para trabajo comercial diario y seguimiento de cartera.
3. Si necesitas ayuda con acceso o migracion operativa, contacta a soporte.
